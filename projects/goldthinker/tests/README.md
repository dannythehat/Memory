## Conventions (fixtures)

- **Test account (fixture, not Vantage's real specification):** tick size 0.01, tick value $1.00 per tick per lot, lot step 0.01, minimum lot 0.01, default spread 0.20, commission 0 unless stated, reference equity $10,000, 1R = $100. Swap fixture: long -5.00, short +2.00 USD per lot per night, rollover 22:00 UTC, triple on Wednesday.
- **Test calendar (fixture; the real Vantage calendar is still "TO CONFIRM"):** open Sunday 23:00 UTC to Friday 22:00 UTC; daily pause Monday-Thursday 22:00-23:00 UTC; server time UTC+1 with no DST for D1/W1/MN1 boundaries.
- **Exact arithmetic.** Integer ticks and exact rationals (A-22); boundary vectors sit exactly on the line; values such as `74/47` are exact fractions (decimal approximation shown in the docs).
- **Context injection.** In pattern vectors ATR is 4.00 unless stated and trend/zones/swings/RSI are supplied; the global and end-to-end vectors compute those values from bars. Bars are **bid** OHLC (plus ASK bars where A-26 needs them); ticks carry bid and ask. Detection uses bid; BUY executes at the ask, SELL at the bid.
- **Every boundary probe names the clause it isolates**; the calculator checked that exactly that clause fails.

## How the vectors were checked

Every expected value was written by hand or by a stated formula first and then compared with an independent scratch calculator written from the spec text (exact rational arithmetic, per-clause evaluation, calendar, tick paths, hub aggregation): all 1408 vectors agree (0 mismatches). Hand-derived spot checks (swap 65/33 and 161/80, MAX_HOLD 14/33 and 1/3, quantised stops/targets, ATR 7613/1400) matched the calculator. The end-to-end intermediate values (ATR, swing pivots, zones, RSI) were recomputed by separate code. **Limits:** the same author wrote the vectors and the calculators from one reading of the spec, so this proves internal consistency and arithmetic, not intent; a real implementation must be run against `golden_vectors.json`, and the reviewer has accepted RULINGS.md (A-01 replacement included). The calculator is scratch code and is not stored in the repository (D-005).
